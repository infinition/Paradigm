# Results

Compact machine-readable outputs and short reports for executed Paradigm experiments.

```text
results/
  core_p0/
  core_p01/
  core_p02/
  core_p03/
  core_p04/
  core_p05/
  core_p10/
  core_p11/
  core_p12/
  core_p13/
  core_p14/
  core_p20/
```

Every recorded result should include the exact seed, environment metadata where applicable, and a benchmark command that regenerates it.

`core_p05/runtime_store/` is a small recorded lifecycle artifact used to inspect the persistent benchmark. It contains trusted local pickle payloads generated by the benchmark. Do not load pickle artifacts from an untrusted source.

Large checkpoints and datasets should remain outside Git history.

- `core_p11/`: multi-layer continual adaptation and explicit neural update-space control.
- `core_p12/`: family-conditioned trusted plasticity and replay plus bounded-update comparison.
- `core_p13/`: persistent family registry and family lifecycle controls.
- `core_p14/`: guarded family topology evolution and non-permissivity controls.
- `core_p20/`: first coding-agent vertical, controller-reflex compilation, OOD fallback, and deliberative-call reduction.
- `core_p21/`: online agent learning, outcome-filtered experience buffer, and novel-family acquisition during sequential use.
- `core_p22/`: real LLM controller integration. Contains a live benchmark against a local language model, including compilation cost, evaluation savings, and the reflex amortization metric. In a snapshot without a configured live endpoint, the report instead records explicitly that no live model benchmark was executed.
- `core_p23/`: real LLM online acquisition. Per-episode cumulative cost curves, promotions and rejections, time-to-reflex, unknown false fast-path rate, and old-family retention for the P2.1 stream with a real model as the only teacher.
- `core_p23r/`: P2.3 replication matrix over seeds, models, and novel-family arrival orders, with per-run artifacts under `runs/`, transport controls under `transport_control/`, an aggregate summary, and a narrative interpretation.
- `core_p23r_bis/`: family-aware certification with retention probes against the recent-split rule, shadow certifier records, disagreement matrix, negative control, and a sensitivity run.
- `core_p23t/`: learning-threshold sweep with fixed certification, cached LLM-only traces per model, capability versus gate acceptance curves.
- `core_p24/`: Type B skill acquisition on the dependency_error family (one-page `SUMMARY.md`, replayable with `paradigm benchmark p24 --from-cache`): teacher traces and statistics, k = 0 control, capability versus evidence sweep with fixed certification, online acquisition runs, and a frozen post-stream evaluation on fresh tasks.
- `integration_laruche/`: real LaRuche missions with DeepSeek through the Paradigm bridge, 32 of 32 verified by pytest, no reflex promoted under whole-candidate certification; see `docs/INTEGRATION.md`.
