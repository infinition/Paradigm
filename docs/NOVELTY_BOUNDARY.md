# Novelty boundary

Paradigm should not be presented as inventing any of the following ideas:

- fast and slow decision systems
- distillation from expensive reasoning into direct prediction
- model cascades
- confidence-based abstention
- continual learning
- policy distillation
- out-of-distribution detection
- active and candidate deployment patterns

These are established areas.

## Research hypothesis

The narrower Paradigm hypothesis is that repeated validated deliberative behavior can be treated as a compilable artifact with a measurable lifecycle:

```text
experience -> select -> compile -> calibrate -> constrain -> evaluate -> promote -> monitor -> retire
```

The project becomes interesting only if this lifecycle produces a better cost, latency, reliability, or adaptation tradeoff than simpler alternatives.

## Potential contribution, if supported

A defensible contribution would combine:

1. automatic selection of behavior worth compiling
2. separately deployable specialized reflexes rather than one continually rewritten policy
3. calibrated fallback as part of the runtime contract
4. trusted-space and bounded-plasticity mechanisms tested as explicit controls
5. structure-aware choice of reflex substrate
6. predictive-state gating for actions where future state matters

No item should be called novel until the relevant literature review and experiment are complete.

## Family-conditioned trusted plasticity

Paradigm does not claim novelty for subspace methods, prototype classifiers, continual-learning replay, or risk-aware learning rates individually.

The current project-specific hypothesis is the lifecycle combination: validated deliberative behavior is compiled into reflexes whose updates are compared within an explicit model lineage and behavior family, bounded by an interpretable plasticity budget, checked against independent behavior and semantic evidence, then managed through immutable active/candidate and family lifecycles.

P1.1 is important to this boundary because it shows what Paradigm is not: one global neural update manifold interpreted as a semantic certificate. P1.2 and P1.3 narrow the mechanism to additive family definitions, explicit fallback for unknown behavior, and separate operational quarantine.


P1.4 adds a narrower lifecycle hypothesis: family topology should evolve through explicit immutable replacements and measured non-permissivity checks rather than by silently relaxing thresholds on existing trusted regions. This is a project design hypothesis, not a novelty claim about clustering, open-set recognition, or prototype routing.

## Agent vertical

P2.0 is an application benchmark, not a separate novelty claim. Routing repeated agent-control decisions through a compact classifier is not novel by itself. The research question is whether that fast path can be integrated with Paradigm's explicit compilation, OOD fallback, family lifecycle, bounded plasticity, promotion evidence, and rollback without hiding the cases that still require deliberation.
